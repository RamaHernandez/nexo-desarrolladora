# Nexo Constructora - Landing premium

Proyecto demo hecho con Vite + React + Tailwind.

## Correr el proyecto

```bash
npm install
npm run dev
```

## Build para producción

```bash
npm run build
```

## Notas

- La paleta ahora está orientada a una constructora premium: negro, grafito, arena y cobre.
- Tailwind está fijado en versión 3.4 para evitar el error de PostCSS con Tailwind v4.
- Cambiar el WhatsApp en `src/App.jsx` buscando `wa.me/5491112345678`.
- Cambiar datos de contacto, textos e imágenes desde `src/App.jsx`.
